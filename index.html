Connect GitHub to save changes

This site is hosted on GitHub Pages, so changes are saved by committing a small file called data.json to the repository. To do that, this browser needs a GitHub access token.

  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and choose Generate new token.
  2. Under Repository access, choose Only select repositories and pick cs4366-Geek_Squad.
  3. Under Permissions, Repository permissions, set Contents to Read and write.
  4. Generate the token, copy it, and paste it below.

If GitHub rejects a teammate's fine-grained token because they do not own the repository, they can create a classic token with the repo scope instead.

The token stays in this browser only. Never share it or put it in the page's code.
